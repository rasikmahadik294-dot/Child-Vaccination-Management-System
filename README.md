# Child Vaccination Management System

A web-based application developed to manage and maintain child vaccination records and related information.

## Technologies Used
- ASP.NET
- C#
- SQL
- HTML
- CSS
- JavaScript

## Features
- Child Registration
- Vaccination Record Management
- Child and Parent Information Management
- Vaccination Details Tracking
- Database Management

## Project Overview
This system helps manage child vaccination information in an organized way. It allows users to maintain vaccination records and easily access important details related to a child's vaccination history.
